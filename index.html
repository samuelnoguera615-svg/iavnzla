📲 ¿Cómo instalar en Android correctamente?

  1. Si Chrome avisa: "El archivo puede ser dañino", presiona "Descargar de todos modos".
  2. Para abrir el archivo: Ve a la app "Archivos", "Mis Archivos" o "Descargas" de tu teléfono y toca iavnzla.apk desde allí (evita abrirlo directo desde la barra de Chrome si dice que no se puede abrir).
  3. Permisos: Si aparece "Tu teléfono no tiene permitido instalar apps desconocidas", toca en Ajustes / Configuración y activa "Permitir desde esta fuente".
  4. Si tuviste una versión anterior: Desinstálala antes de instalar esta nueva versión limpia.
